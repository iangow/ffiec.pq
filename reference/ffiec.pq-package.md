# ffiec.pq: FFIEC Call Report Processing Tools

Tools for downloading, parsing, and processing FFIEC Call Report bulk
data, including conversion to Parquet format and integration with
DuckDB.

## Details

The package supports workflows in R, Python, and SQL by producing
columnar Parquet files with consistent schemas and metadata.
